## Cheat Sheet

### Topics

1. HTTP + REST API design - HTTP methods, status codes, headers, cookies, CORS, idempotency, REST conventions, pagination / filtering / sorting
2. Authentication - access token vs refresh token, session-based auth vs jwt auth, high level oauth flow (JWT, sessions, cookies, OAuth basics)
3. SQL (especially querying, filtering, mofifying / updating, group, joins, indexes, transactions, relationships, orm, migrations)
4. Backend project structure (controller → service → repository -> database)
5. Redis and caching - cache-aside, ttl, cache invalidation, sessions in redis
6. Linux basics - ps, top, grep, find, tail, chmod, ssh, systemctl
7. Security - XSS, CSRF, SQL injection, password hashing, HTTPS/TLS
8. System design fundamentals - load balancing, horizontal and vertical scaling, message queues,
